# Changelog

## 1.0.1 — 2026-11-01

- Add a repository marketplace so the plugin can be distributed through GitHub.
- Add the MIT license, bilingual README, contribution guide and release instructions.
- Add CI checks for Node.js 22 / 24 and clean sharing-package verification.
- Support Windows Codex installations using npm's `codex.cmd` wrapper without passing arguments through a shell.
- Preserve original files without a trailing newline when detaching a project.
- Decode split UTF-8 request bodies correctly, including Chinese project paths.
- Explain invalid ports, occupied ports and CLI option errors clearly.
- Refresh the browser session when reopening a restarted Hub with a new token.

## 1.0.0 — 2026-11-01

- Local skill discovery, duplicate detection and source-aware selection.
- Seven starter bundles, curated boundaries and conflict detection.
- Chinese management panel, search, favorites and saved combinations.
- Project preview, apply, undo and detach.
- Desktop routing and an optional focused Codex CLI launcher.
- Local plugin installer and portable sharing ZIP.
